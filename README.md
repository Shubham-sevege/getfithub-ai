# 🧠 GetFitHub.AI – AI Fitness & Diet Planner

🚀 An AI-powered web application that generates personalized workout plans and diet recommendations based on user goals.

---

## 📌 Features

* 🏋️ Personalized workout plans (Beginner → Advanced)
* 🥗 AI-generated diet plans (veg-focused, Indian-friendly)
* 📊 Goal tracking (fat loss, muscle gain, maintenance)
* 🤖 Smart recommendations using AI logic
* 📱 Responsive design (works on mobile & desktop)

---

## 🛠️ Tech Stack

* Frontend: HTML, CSS, JavaScript (or React)
* Backend: Node.js / Python (Flask)
* Database: JSON / MongoDB
* AI Logic: Rule-based + future ML integration

---

## 🎯 How It Works

1. User enters:

   * Age, weight, height
   * Fitness goal (fat loss / muscle gain)
2. System processes input
3. AI generates:

   * Workout split
   * Diet plan (calories + protein)
